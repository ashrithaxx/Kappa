# Week 4 — FinTech Product

Turns the Week 1-3 quant engine into a usable product: a FastAPI backend and a
browser dashboard, deployable for free.

## What was added
- `app/api/main.py` — FastAPI service. Every endpoint validates input with
  Pydantic, then calls straight into the existing `app/quant` /
  `app/models` code — no logic is duplicated.
- `static/index.html` — single-page dashboard (vanilla JS + Plotly CDN, no
  build step) with four tabs mirroring the four quant modules.
- `Procfile`, `render.yaml` — free-tier deployment configs.

## Endpoints
| Method | Path | Purpose |
|---|---|---|
| POST | `/api/gbm/simulate` | Simulate GBM price paths |
| POST | `/api/options/price` | MC option price vs. Black-Scholes |
| POST | `/api/options/convergence` | Convergence sweep across sample sizes |
| POST | `/api/portfolio/simulate` | Portfolio P&L, VaR, Expected Shortfall |
| POST | `/api/portfolio/stress-test` | Baseline vs. shocked-scenario comparison |
| GET | `/api/health` | Liveness check |

Interactive schema/docs: `/docs` (Swagger UI, auto-generated by FastAPI).

## Run locally
```bash
pip install -r requirements.txt
uvicorn app.api.main:app --reload
# open http://127.0.0.1:8000
```

## Deploy (free tier)
**Render** — push to GitHub, create a new Web Service from the repo; it
reads `render.yaml` automatically. **Railway/Fly.io** — same idea, using the
included `Procfile`. No database or paid add-ons required.

## Notes
- The dashboard assumes a flat off-diagonal correlation (0.2) between
  portfolio assets for simplicity; the API accepts any valid correlation
  matrix if you script against it directly.
- Simulation counts are capped server-side (options: 1M, GBM/portfolio: 50K
  paths from the UI) to keep response times interactive; the underlying
  engine has been validated up to 1M+ paths in the Week 1-3 notebooks/tests.
